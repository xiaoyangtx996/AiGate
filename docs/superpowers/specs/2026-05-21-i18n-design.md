## 四、语言切换实现

### 4.1 切换入口

顶栏右侧添加语言切换下拉菜单：
- 中文（简体）
- English
- 日本語

### 4.2 持久化

```typescript
// 写入 localStorage
localStorage.setItem('aigate_language', 'zh')

// 读取优先级：
// 1. localStorage 存储的语言
// 2. 浏览器语言检测
// 3. 默认中文
```

### 4.3 切换行为

- 选择语言后立即生效（无需刷新）
- 顶栏语言切换显示当前语言名称
- 语言变更触发所有组件重新渲染

3. 创建翻译文件目录结构
4. 在 main.tsx 中初始化 i18n

1. 提取所有页面的硬编码文案
2. 按页面分类创建翻译文件
3. 编写中文翻译（基准）

2. 所有页面文案正确显示
